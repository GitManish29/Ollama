## About

This project demonstrates the Ollama base model **Gemma-3B** using Jupyter Notebook, providing an interactive environment for exploring and testing the model's capabilities.

---

## Installation

### Prerequisites

- **Node.js** (v14 or higher)
- **npm** (v6 or higher)
- **Python** (v3.7 or higher)
- **Jupyter Notebook**

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GitManish29/Ollama.git
   cd Ollama
   ```

2. **Install Node.js dependencies:**
   ```bash
   npm install
   ```

3. **Install Python dependencies (if applicable):**
   ```bash
   pip install -r requirements.txt
   ```

4. **Start Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```

## Usage

1. Open your browser and navigate to `http://localhost:8888`
2. Open the Jupyter Notebook file
3. Run the cells to interact with the Ollama Gemma-3B model
